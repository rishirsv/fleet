Results

  • Fleet and Anthropic tie overall, for very different costs. Both average 7.33 overall and the same average rank, 1.67; no plugin averages 6.67. Across all nine dimensions Fleet is slightly ahead, 7.70 against 7.56. Anthropic gets there with a tenth of the guideline words and about two-thirds of the tokens.
  • Fleet won the two product UIs: first on the phone app (8 against 7 and 7) and on the web app (8 against 7 and 6). The grader named its states, platform behavior, copy and timing as the reasons: shape-coded statuses, the table adapting at tablet width, 240ms motion, and budget-specific copy such as "$76 a day for 12 days".
  • Anthropic won the marketing site (8 against 7 for no plugin and 6 for Fleet), and scored highest on fitting each design to its subject: 8.7 on average, against 7.0 for Fleet and 4.3 with no plugin. Its ideas were specific to the brief: a library checkout card, a depot yard board, a sentence-led budget.
  • Requirements are not where any plugin earns its keep. The runs with no plugin met 26 of 28 requirements. The plugins add taste and finish, not coverage.
  • Both plugins remove the generic look. Every no-plugin build showed template tells: identical shadowed cards, uppercase eyebrow labels, middle-dot metadata, and cream with serif and terracotta. The plugin builds showed one each at most.

What to remove

  • Files that are read but can't act. evidence.md and finish-review.md were read in every Fleet run (about 150 lines), and then skipped because no browser or reviewer was available. Route to them only when the agent can render or delegate.
  • The accessibility guide on the build path. It was read in two of three builds, though you've set accessibility aside.
  • Overlapping always-read files. context-contract.md, craft-floor.md and direction.md are read together on every build and repeat each other. Fold them into one short direction file.
  • The landing-page strategy template. The Fleet homepage run read landing-page-design and its 121-line strategy file, and came last with "a text block beside an empty half-screen". The 12-section conversion template pulled it toward a generic marketing structure. Make that file apply only to conversion and campaign pages.

What to add

  • Anthropic's direction process. frontend-design frames the agent as a design lead whose client rejected templated work, writes a token plan, and then reviews the plan against the brief before building. Fleet's direction.md reworded the bans but lost that framing and the review step, and Fleet scored lower on fit. Fork that text into direction.md verbatim.
  • Restraint shouldn't flatten the hero. The grader's fix for the Fleet homepage was to give the hero a visual anchor. Add a line that restraint applies to everything around the one bold idea, not to the idea itself.
  • Keep prototype controls out of the product. Fleet's web app put a "Prototype controls" button in the product header. Demo switches belong outside the design, visibly not part of it.
  • Check both themes against the generic list. Fleet's phone app followed the system dark theme and landed on the near-black and green look the bans name.

Token efficiency

  • Fleet cost about 53% more than Anthropic (142k tokens against 93k per run) and about 60% more time. It read 15–18 files where Anthropic read 3–5. A no-plugin run cost 88k tokens.
  • The order of work invites reading everything. Fleet's router lists craft, motion, icons, layout, typography and color references for every build, and agents read them all up front. Make direction.md the one file read before building, and the craft references lookups when a specific question comes up.
  • Aim for about 25k words. Anthropic's plugins reach most of the quality at about 5,400 words. Fleet's extra value is concentrated in a few files (interaction, layout, motion, UX copy). Those plus a direction file would land near 25,000 words, about half of today.
