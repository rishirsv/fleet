# Design provenance

Domain workflows and the design-system runtime originated in
[rishirsv/kpmg](https://github.com/rishirsv/kpmg/tree/e280ec79a24188bfbf940da4483d0e64e99ca30b/reference/claude-artifact-plugins),
revision `e280ec79a24188bfbf940da4483d0e64e99ca30b`.
[origin.json](origin.json) records the original file hashes and paths.

The seven full workflow bodies are maintained under `plugins/design/references/`;
the runtime and complete format documentation are under `plugins/design/design-system/`.
Host-specific instructions are adapted to actual capabilities. Required runtime
API identifiers and loader filenames are retained for compatibility.

No license file accompanied the source directories. Public redistribution needs
a rights check; removing branding does not change those obligations.
