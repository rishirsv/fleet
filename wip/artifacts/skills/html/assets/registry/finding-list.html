    Verification and publication use different candidates

    Evidence. The release task rebuilds after the final validation step, so the uploaded archive is not the proven artifact.

    Consequence. A passing check cannot establish what shipped.

    Action. Freeze one candidate, verify it once, and pass that exact path to publication.

    The failure receipt omits the owning stage

    Evidence. The summary reports only a final non-zero exit code.

    Action. Preserve the stage name and focused command in the receipt.
