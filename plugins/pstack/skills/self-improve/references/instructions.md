# Agent instruction changes

Identify the maintained source and how the active host discovers or generates
it. Codex global AGENTS.md and Claude global CLAUDE.md have different discovery
rules; Claude may import repository AGENTS.md explicitly. Preserve managed
markers and local overlays. Edit the owner, not a generated copy or memory store.

Place a rule at the narrowest useful scope. Repository commands belong with the
repository, tool mechanics with the tool, workflows with their skill and personal
preferences with personal guidance. Before adding a correction, determine whether
an existing rule was missing, unavailable, ambiguous or bypassed.

Use [correct](correct.md) for the enforcement hierarchy when a recurring
repository mistake is established. State why stronger enforcement is unavailable
or disproportionate. Keep
instructions for real decisions and constraints the environment cannot supply;
delete duplicate generic guidance instead of replacing it with a larger index.

Show the exact proposed change, owner, evidence and verification. Distinguish a
source-visible contradiction from a causal claim requiring task evidence. Preserve
permissions, exceptions, selected settings and machine-specific protections. An
audit request alone does not authorize applying configuration across machines.
