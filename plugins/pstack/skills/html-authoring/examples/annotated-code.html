Keep the newer draft intact.

A version check turns an accidental overwrite into an explicit conflict.

Illustrative TypeScript · Notes app · This is an explanation of a proposed change, not a review of a real repository.

Send the version the editor started from. If the server has moved on, keep the local draft and ask the user to resolve the conflict.

The change

The previous request sent only the draft body. This version carries a precondition and distinguishes conflicts from other failures.

− await putDraft(id, { body });
+ const result = await putDraft(id, { body, expectedVersion });
+ if (result.status === 409) return showConflict(body);

Line 6: reject stale writes

The server must compare and update the version atomically. Sending the field alone provides no protection.

Server contract required

Lines 8–10: keep the local copy

The conflict view retains this draft and replaces the saving state. It must not retry the same write automatically.

Line 16: make failure visible

A network or server failure leaves the draft available for retry. The editor must not display “Saved”.
